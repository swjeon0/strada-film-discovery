# STRADA 큐레이터 1.5단계 품질 파일럿

> 단계 1.5의 역사 기록입니다. 현재 문헌 DB 연결과 배포 검증은 `../knowledge/stage-2-3-report.md`를 봅니다.

## 현재 판단

현재 구조는 운영 후보로 사용할 만큼 단순해졌다. 선택작 전체를 같은 비중으로 읽는 메인 큐레이터가 정확히 12편의 프로그램을 한 번에 만든다. 문헌은 판단을 돕지만 후보 목록을 제한하지 않는다. 코드가 실제 작품 정체성을 확인하고, 식별에 실패한 자리만 예외적으로 한 번 교체한다. 사용자에게는 검증된 12편만 보낸다.

이 단계에서 확인한 것은 **좋은 큐레이션이 가능한 구조와 20초 안의 실행 가능성**이다. 최상급 인간 큐레이터를 넘었다는 결론은 아직 낼 수 없다. 현재 표본은 작고, 독립된 인간 패널 평가는 시작 전이다.

## 큐레이션 원칙

프롬프트는 영화들을 반드시 하나의 비평적 질문이나 추상적 논제로 환원하지 않는다. 모델은 선택작에서 출발해 가장 정확하고 탐색 가치가 높은 프로그램을 짜면 된다. 직접적인 사실 관계와 복잡한 형식적·미학적·역사적 해석을 같은 기준으로 판단하며, 연결의 종류나 복잡성 자체에는 가산점을 주지 않는다.

목록에 감독·국가·시대별 quota는 없다. 반복은 새 정보를 만들 때 허용하며, 다양성은 그 자체로 점수를 얻지 않는다. 개별 추천이 선택작 하나를 깊게 파도 되지만 12편 전체는 모든 선택작을 의미 있게 다뤄야 한다.

## 온라인 경로

1. 선택한 1–8편의 canonical metadata와 줄거리를 읽고 순서와 무관하게 정렬한다.
2. 저장소에서 선택작과 직접 연결된 사람 검토 문맥을 최대 16개 가져온다. 문헌이 없는 영화도 그대로 진행한다.
3. `gpt-5.6-terra`, reasoning `none`이 정확히 12편의 단일 ranked programme을 만든다. 메인 호출 제한은 15.75초다.
4. 로컬 catalogue와 TMDB가 12편을 검증한다. 제목, 원제, 대체 제목, 감독, 개봉연도를 함께 보고, 제목 검색이 약하면 감독 검색 → 연출 credits → 영화 상세 순으로 확인한다.
5. unresolved, duplicate, excluded 슬롯이 있으면 `gpt-5.4`, reasoning `none`이 그 자리만 한 번 교체한다. 현재 목록의 연결과 전체 관점을 함께 주고, 새 후보 풀이나 reserve는 만들지 않는다. 제한은 3.75초다.
6. 수정된 12편 전체를 다시 검증한다. 12편이 모두 통과할 때만 응답한다. 부분 목록은 내보내지 않는다.

복구 호출은 큐레이션을 조각내기 위한 단계가 아니다. 메인 모델이 이미 결정한 프로그램에서 잘못된 작품 정체성만 고치는 예외 처리다. 보통 실행에는 호출되지 않는다.

## 작품 식별에서 고친 오류

이전 resolver는 제목과 연도가 유일하게 맞으면 감독이 다른 동명 작품도 받아들였다. 실제로 *The Impostor*의 설명은 Bart Layton 작품을 가리키는데 다른 감독의 동명 영화 ID를 붙인 사례가 있었다. 이 fallback은 삭제했다.

반대로 실재하는 비주류 작품은 제목 검색에서 빠졌다. 이제 감독의 연출 filmography까지 확인해 *Empire*, *D’Est*, *A Letter from Siberia*를 찾을 수 있다. TMDB의 배급연도와 통상 제작연도가 다른 *Hôtel Monterey*, 배급 제목과 통상 제목의 철자가 다른 *Nostalghia*도 검증된다. 감독·제목 또는 대체 제목·연도가 유일하게 함께 맞지 않으면 계속 거절한다.

## 속도와 완성도 측정

최신 설정의 12개 고정 조합은 여러 targeted regression의 각 조합별 최신 성공 실행을 합치면 모두 실제 영화 12편을 반환했다. 이 집계는 한 번의 동시 acceptance run이 아니라 수정 과정에서 축적한 최신 실행을 이어 붙인 회귀 근거다.

| 지표 | 결과 |
|---|---:|
| 최신 성공 실행 | 12 / 12 조합 |
| 20초 안의 성공 | 12 / 12 조합 |
| 총시간 p50 / p95 / max | 12.916초 / 15.521초 / 15.521초 |
| 평균 총시간 | 13.097초 |
| 성공 응답의 표시 영화 수 | 전부 12편 |

실패를 숨기지는 않았다. Terra의 난제 재실행에서는 존재를 확인할 수 없는 작품명, 입력작의 변형 제목, canonical duplicate가 실제로 나왔다. 대체 제목과 filmography resolver가 실재 작품의 false negative를 줄였고, 슬롯 복구 경로가 나머지 identity 오류를 처리한다.

복구 모델을 고르는 작은 비교에서는 `gpt-5.4-mini`가 2.017초에 기존 목록의 *Landscape Suicide*를 다시 골라 실패했고, `gpt-5.4`는 1.523초에 새 작품 *Workers Leaving the Lumière Factory*를 골랐다. 후자는 TMDB에서 1895년 Louis Lumière 작품으로 다시 검증됐다. 이 때문에 드물게 실행되는 복구에는 더 강한 `gpt-5.4`를 사용한다. 이 한 슬롯 표본은 복구 성공률의 통계적 증명이 아니라 설정 선택의 근거다.

`gpt-5.4`를 메인 큐레이터로 쓴 세 난제에서는 reasoning `none`이 1/3만 완성됐고, `low`는 3/3 모두 17.5초 timeout이었다. 메인 모델은 블라인드 표본 품질과 속도가 더 나았던 Terra를 유지했다.

## 블라인드 품질 파일럿

같은 Terra와 같은 v2 프롬프트로 문헌 문맥이 없는 조건과 현재 snapshot을 제공한 조건을 가려 비교했다. 다섯 조합에서 snapshot 조건은 5/5를 완성했고 p50 12.669초, p95 15.521초였다. 빈 문맥 조건은 4/5를 완성했다.

두 명의 LLM proxy가 조건 이름을 모른 채 목록을 평가했다. 이 평가는 출시 gate에 쓰지 않는다. 열 개의 pairwise 판단을 합치면 snapshot 조건 7승, 빈 문맥 조건 2승, 동률 1회였다. 좋은 결과의 공통점은 어려운 비평 용어가 아니라 각 영화가 구술, 공연, 제작 관계, 가정 공간, 실제 경과 시간처럼 프로그램 안에서 분명한 역할을 가진다는 점이었다. 약점은 입력 전체를 읽었다고 말하면서 한 작품의 넓은 주제만 반복하거나, 한 감독의 작품을 많이 넣고도 각 자리의 추가 가치를 설명하지 못하는 경우였다.

이 결과는 문헌이 후보 DB로 작동해서 좋아졌다는 뜻이 아니다. snapshot은 모델이 선택작을 더 정확히 읽도록 도운 문맥이고, 추천작 대부분은 여전히 모델 지식에서 나왔다. 작은 snapshot의 감독 편향도 남아 있다.

## 평가 기준

앞으로는 정답 영화 적중률을 품질로 쓰지 않는다. 블라인드 평가자는 다음 여섯 축을 각각 본다.

1. 입력 영화들에서 설득력 있는 큐레이션의 출발점을 찾았는가.
2. 각 영화가 왜 이 경로에 속하는지 구체적이고 정확한가.
3. 각 선택이 실제로 다음 영화를 볼 이유를 주는가.
4. 가능한 연결 중 이 12편을 고른 판단이 뛰어난가.
5. 반복을 포함한 모든 자리가 하나의 유용한 프로그램으로 작동하는가.
6. 작품 정보와 관계의 강도를 정직하게 다루는가.

추상적 문제의식, 감독 다양성, 낯선 영화의 수는 독립된 목표가 아니다. 그것들이 실제 프로그램을 더 좋게 만들 때만 결과에 반영된다.

## 남은 검증

현재 12개 조합과 두 proxy로 인간 큐레이터 이상의 성능을 주장할 수 없다. 다음 단계의 최소 gate는 다음과 같다.

- 개발에 사용하지 않은 40개 이상의 선택작 조합
- 영화 지식이 있는 독립 평가자 최소 3명
- 각 목록의 절대 점수와 A/B/tie를 모두 수집
- 치명적 사실 오류 0건
- 평균적으로 12편 중 8편 이상이 `strong` 또는 `useful`
- 최소 200회 end-to-end 실행에서 exact-12 성공률과 20초 p95 측정

현재 구조는 이 평가를 진행할 수 있는 상태다. 다음 판단은 프롬프트를 더 복잡하게 만드는 일이 아니라, 실패 조합과 사람의 선택 데이터를 모아 어떤 큐레이션 판단이 실제로 유용했는지 확인하는 일이다.
