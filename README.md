# STRADA

공개 사이트: https://strada-film-discovery.vercel.app

영화에서 다음 영화로 이어지는 디깅 서비스입니다. 검색·포스터·한국어 제목·줄거리는 TMDB의 실제 메타데이터를 사용합니다. 추천은 GPT가 읽을 수 있는 비평, 영화제 프로그램과 학술 자료를 참고해 생성합니다. 가입이나 영화 데이터베이스 없이 브라우저에 경로를 저장합니다.

## 실행

Node.js 22와 npm을 사용합니다.

```sh
npm ci
cp .env.example .env.local
npm run dev
```

`.env.local`의 `OPENAI_API_KEY`, `TMDB_READ_ACCESS_TOKEN`을 채웁니다. 로컬 개인 개발에서는 `PUBLIC_MODE=false`로 설정할 수 있습니다. 서버 주소는 http://127.0.0.1:5173 입니다.

## GitHub + Vercel 배포

GitHub 비공개 저장소: https://github.com/swjeon0/strada-film-discovery

Vercel의 STRADA 팀에서 이 저장소를 연결합니다. Framework는 Next.js, 프로젝트 루트는 저장소 루트입니다. `main` 브랜치 변경을 Production에 자동 배포합니다. `npm run build`는 동일한 표준 Next.js 배포 빌드입니다.

Production과 Preview 환경변수에는 다음 값을 등록합니다. API 키에는 `NEXT_PUBLIC_` 접두사를 붙이지 않습니다.

- `OPENAI_API_KEY`
- `OPENAI_SEARCH_MODEL=gpt-4.1-mini` (웹 출처 검색; 기존 `OPENAI_MODEL`도 검색용 별칭으로 지원)
- `OPENAI_CURATOR_MODEL=gpt-5.4-mini` (공동 해석, 후보 선별, 상세 설명; 추론 강도 low)
- `TMDB_READ_ACCESS_TOKEN`
- `QUOTA_SERVICE_URL`
- `QUOTA_SERVICE_SECRET`
- `PUBLIC_MODE=true`

앱과 모든 영화 API는 Vercel의 Node.js 서버에서 실행됩니다. 비용 제한 카운터만 기존 Cloudflare Durable Object에 유지합니다. `infra/quota`는 Vercel 서버에서 이 카운터에 접근하는 인증 전용 연결입니다. 기존 `strada-film-discovery`의 `AiQuota`와 `strada-ai-budget` 객체를 그대로 사용하므로 기존 날짜별 제한이 보존됩니다. 이 기존 객체를 삭제하면 비용 확인이 실패하며 GPT 호출도 차단됩니다.

이 카운터에는 영화 기록이나 원본 IP를 저장하지 않습니다. 날짜와 호출 범위를 해시한 식별자, 횟수와 시간만 저장합니다. 서비스 전체 하루 50회의 새 탐색·상세 확장을 허용하며, 새 탐색은 사용자별 10분에 6회입니다. 상세 확장은 서버가 서명한 연결별 범위를 사용해 탐색 횟수를 소진하지 않으며, 로컬 사용자 제한은 별도로 10분에 24회입니다. 상세 확장도 같은 전역 일일 한도를 차감합니다. 한 번의 탐색에는 여러 모델 호출이 포함되며 캐시 재사용은 새 유료 호출을 만들지 않습니다. 비용 값은 API 사용량 기반 추정치이며 중단된 호출에서 사용량을 받지 못하면 실제 청구가 더 클 수 있습니다.

`.env.local`, `.vercel`, 인증 파일, 개발 로그는 GitHub에 올리지 않습니다. 저장소와 ZIP에도 비밀 키를 포함하지 않습니다.

## 추천 동작

추천은 전문 레퍼런스 DB 없이 실행하는 A안입니다. 선택 영화의 실제 정보와 줄거리 → 2~3개의 공동 해석 관점 및 후보 최대24편 → 작품 식별과 목적별 비평 검색 병렬 처리 → 자료를 반영한 최종12편 선별 순서입니다. 구조화된 후보에는 관점, 선택 영화와의 연결, 생산적인 차이, 확인할 주장이 들어갑니다. 핵심 큐레이터 호출은 기본2회이며, 출처가 있다는 이유만으로 우선순위를 올리지 않습니다. 비평 자료를 찾지 못해도 AI 해석으로 추천을 채우고, 작품 식별이나 새 영화 확보가 부족하면 조건을 어기는 대신 부분 결과를 명시합니다.

모든 시작·따라가기·직접 추가 영화는 순서와 관계없이 같은 비중입니다. 두 편 이상 선택하면 후보는 최소 두 선택을 함께 읽는 연결을 제안하도록 구성합니다. 과거에 표시만 된 영화는 취향으로 간주하지 않습니다. 정렬은 큐레이터의 형식적·역사적 판단을 사용하며, 코드가 중복과 새 영화 조건을 강제합니다.

‘다른 영화 찾기’는 현재 경로에서 이전에 표시된 모든 추천을 제외하고 같은 선택으로 재생성합니다. 따라가기와 직접 추가는 직전12편 중 최대5편만 유지합니다. 부분 결과에서도 절반을 넘는 새 영화를 보장합니다. 성공한 요청만 스냅샷으로 저장하며, 재생성은 경로에 영화 한 편을 추가한 것으로 계산하지 않습니다. Undo, 경로 기록, 브라우저 이동은 저장된 정확한 스냅샷을 복원합니다. 되돌린 뒤 다른 길로 이어가도 버려진 분기에서 표시한 영화 ID는 제외 기록에 남습니다. 최근 최대64개 스냅샷을 저장하고, 오래된 스냅샷을 줄여도 제외할 영화 ID는 보존합니다(최대5000개; 한도 도달 시 명시적으로 새 경로 안내). 새 경로를 시작하면 이 제외 기록을 초기화합니다.

비평 검색은 시작 영화 확인·관점 확장·후보 확인 질문을 사용하고, 최대3회 검색과8문서를 읽습니다. 접근이 막히거나 본문이 없는 결과는 건너뛰되 최대16개 URL과 전체 시간 예산을 넘지 않습니다. 문서 앞부분 대신 질문과 관련된 문단 및 인접 맥락을 읽습니다. 전문 매체뿐 아니라 작성자와 본문이 확인되는 비평·학술 글도 허용합니다. 최종 선별 호출 안에서 먼저 원문의 관찰과 발췌를 정리하고, 그 관찰을 추천의 비교에 반영합니다. 출처 표시에는 실제로 읽은 본문의 일치 구간이 필요합니다.

비평은 모델이 실제로 읽은 출처의 맥락입니다. 추천 영화와의 비교는 STRADA의 해석이며, 비평가가 그 비교를 직접 했다는 뜻이 아닙니다. 출처가 없으면 AI 해석으로 표시하고 가짜 인용은 만들지 않습니다.

## 실패 복구와 이미지

초기 관점·후보 생성은 최대35초, 자료 수집18초, 최종 선별27초이며 남은 전체 시간 안에서 동작합니다. 서버 전체90초, 브라우저100초, Vercel 함수100초입니다. 처음에는 현재 언어의 짧은 설명만 생성합니다. 포스터를 열면 서명된 연결 정보로 긴 설명을 최대30초 안에 작성합니다. 서명에는 API 키가 포함되지 않으며, 오래된 서명이 만료되어도 기존 짧은 설명은 계속 읽을 수 있습니다.

응답이 잘리면 완성된 원본 JSON 항목만 복구합니다. 최종 선별만 실패하면 확인된 후보의 짧은 초기 해석을 출처 없는 AI 해석으로 표시합니다. 상세 설명 실패는 추천 목록에 영향을 주지 않습니다. 같은 요청의 동시 이용자는 하나의 작업을 공유하고, 마지막 이용자가 취소하면 진행 중인 모델 연결도 중단합니다. 조회 결과와 상세 설명 캐시는 서버 인스턴스 수명에 한정되며 영구 저장소를 가정하지 않습니다.

검색에서 고른 포스터는 선택 후 상세 정보 조회, 추천 생성, 새로고침에도 유지합니다. 이미지가 실제로 로딩되지 않을 때는 검증된 상세 정보의 대체 포스터를 사용합니다.

## 확인

```sh
npm test
npm run typecheck
npm run build
```

새 배포 주소는 기존 Cloudflare 주소와 다른 출처이므로 브라우저 저장 공간도 분리됩니다. 기존 경로는 원래 주소의 브라우저 저장소에 남아 있습니다.
